# Estuda.IA

Plataforma de pesquisa acadêmica multi-agente para estudantes do 3º ano EM.
Cada resposta tem fonte rastreável — o sistema nunca responde do próprio conhecimento.

**Usuária primária:** Catarina, prestando FUVEST, ENEM, UNESP e UNICAMP.

## Stack
Python 3.12 · LangGraph · LlamaIndex · Qdrant · FastAPI · Claude Sonnet 4.6

## Status
Em construção — Q3 2026

## Setup
cp .env.example .env
pip install -r requirements.txt
